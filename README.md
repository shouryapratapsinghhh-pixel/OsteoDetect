# OsteoDetect

Binary classifier distinguishing bone tuberculosis from pulmonary TB on X-ray imagery.

**Hackathon project, 2025** — built as part of a team; I owned the model training pipeline.

- Custom 3-block CNN (TensorFlow/Keras), trained on Google Colab
- Binary classification, 224×224 input, Adam optimizer, binary crossentropy
- **Test accuracy: ~92.69%**

> Note: notebook only — hackathon prototype, not productionized.
